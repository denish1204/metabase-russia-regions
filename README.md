# Карта регионов России для Metabase · Russia Regions GeoJSON
GeoJSON для карты с заливкой по 85 регионам в Metabase OSS.

A lightweight GeoJSON of 85 Russian regions for custom choropleth maps in Metabase Open Source.

# Подключение в Metabase:
1. Откройте файл GeoJSON на GitHub и скопируйте URL кнопки Raw.
2. Перейдите в Администрирование → Настройки → Карты → Кастомные карты → Добавить карту и вставьте URL.
3. Выберите region для идентификатора и отображаемого имени региона.
4. В вопросе выберите Карта → Карта регионов, затем добавленную карту. Укажите колонку с регионом и числовую метрику.
Значения в колонке должны совпадать с properties.region. Например, Республика Татарстан (Татарстан), Камчатский край или Чукотский АО.
# Координаты и источник
Долготы сдвинуты на 15° к западу, чтобы Дальний Восток целиком отображался справа. Файл предназначен для заливки по регионам без географической подложки. Для карт с точками и наложений используйте исходные координаты.
